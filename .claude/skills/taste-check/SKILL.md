# Taste Check (Taste Maker)
Lies zuerst den Skill `nationverse-context` (Fakten und Regeln). Antworte auf Deutsch, außer der Nutzer will etwas anderes.

## Ablauf
1. Screenshot oder Seite ansehen. Zuerst sagen, was funktioniert (1–2 Punkte).
2. Dann maximal 5 Probleme nach Wirkung ordnen: Hierarchie (was sieht man zuerst?), Abstände, Farbkontrast, Schriftgrößen, Ausrichtung, Überladung.
3. Pro Problem eine konkrete Änderung (Wert, Farbe, Abstand).
4. Kein Lob ohne Grund. Wirkt etwas generisch, benenne es.
5. Gesamturteil in einem Satz plus Note 1–10.
