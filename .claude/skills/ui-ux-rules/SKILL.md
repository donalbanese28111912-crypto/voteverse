# UI/UX Rules (Design Lead)
Lies zuerst den Skill `nationverse-context` (Fakten und Regeln). Antworte auf Deutsch, außer der Nutzer will etwas anderes.

## Regeln
- Deutsch, Zahlen im deutschen Format (8.888.888.888), große Beträge zusätzlich als Mio./Mrd.
- Kontrast mindestens WCAG AA, Fokus sichtbar, Bedienung per Tastatur, `prefers-reduced-motion` beachten.
- Mobil zuerst (390 px), kein horizontales Scrollen, Touch-Ziele mindestens 44 px.
- Preise immer mit Einheit (€), Demo-Hinweis sichtbar, „BEISPIEL“-Badge bei Beispieldaten.
- Plattform 1: ruhig, dunkel, Gold-Akzent, exklusiv. Plattform 2: gleiche Marke, aber schlichter, ohne Stufen und Kurven.
- Coin-Bilder kreisrund, ohne weißen Rand; Rückseite passt zur Metallfarbe der Vorderseite.
- Vor Abschluss: Seite im Browser durchklicken, Mobil prüfen, Tests laufen lassen.
