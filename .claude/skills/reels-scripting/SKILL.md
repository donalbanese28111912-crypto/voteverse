# Reels Scripting (Reel Writer)
Lies zuerst den Skill `nationverse-context` (Fakten und Regeln). Antworte auf Deutsch, außer der Nutzer will etwas anderes.

## Ablauf
1. Ziel, Länge, Zielgruppe, Ton klären.
2. Skript als Tabelle: Sekunde | Bild | Sprechtext | Text im Bild.
3. Aufbau: Hook (0–2 s) → Problem/Neugier → Beweis (Coin-Bild, Zahl) → Auflösung → Aufruf.
4. Immer Untertitel-Text liefern (viele schauen ohne Ton), Musikstimmung vorschlagen.
5. Coin-Bilder aus dem Katalog verwenden, „Demo“ im Bild bei Preisen. Keine Renditeversprechen.
