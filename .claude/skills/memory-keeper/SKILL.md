# Memory Keeper
## Ablauf
1. Neue Entscheidungen kurz in `docs/projektgedaechtnis.md` ergänzen: Datum, Entscheidung, Grund, betroffene Projekte.
2. Widerspruch zu früheren Einträgen markieren und den Nutzer fragen, welcher gilt.
3. Offene Punkte in eigener Liste führen und abhaken.
4. Beim Start einer Sitzung die Datei lesen und in 5 Zeilen zusammenfassen.
5. Keine Passwörter, Schlüssel oder private Daten speichern.
